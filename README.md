# راهنما - ساخت APK بدون PC

## مرحله ۱ - قبل از آپلود
1. فایل‌های بازی (index.html + css/js) رو داخل پوشه `www/` بذار
2. فایل `PUT_YOUR_GAME_FILES_HERE.txt` رو پاک کن
3. اگه خواستی، توی `capacitor.config.json` مقدار `appId` و `appName` رو عوض کن

## مرحله ۲ - آپلود به GitHub (از مرورگر گوشی)
1. github.com بساز اکانت (اگه نداری) و یه ریپازیتوری جدید بساز (public کافیه)
2. گزینه "uploading an existing file" رو بزن
3. کل محتوای این پوشه رو (همه فایل‌ها + پوشه‌ها با همون ساختار) بکش و رها کن
4. Commit changes رو بزن

## مرحله ۳ - دریافت APK
1. برو به تب **Actions** توی ریپازیتوری
2. صبر کن (۲-۴ دقیقه) تا تیک سبز بخوره
3. روی run کلیک کن، پایین صفحه بخش **Artifacts** رو باز کن
4. `app-debug-apk` رو دانلود کن -> یه zip میاد که داخلش APK هست

## نکته مهم
این APK **debug** هست یعنی برای نصب مستقیم روی گوشی (فعال کردن "منابع ناشناس") کاملاً کاره.
برای انتشار روی مایکت بعداً نیاز به یه مرحله امضای release داری که جدا می‌تونیم انجامش بدیم.
